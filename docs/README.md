# CreditExplain BR — Guia de leitura

Esta pasta reúne a edição pedagógica e a trilha de evidência do projeto.

## Ordem recomendada para leitores

1. [`miniguia-creditexplain-br.md`](miniguia-creditexplain-br.md) — **e-book principal**, 2ª edição revisada e ampliada.
2. [`siglas-e-abreviacoes.md`](siglas-e-abreviacoes.md) — **mapa de siglas e abreviações**, recomendado para leitores não especialistas.
3. [`apendice-tecnico-regulatorio-creditexplain-br.md`](apendice-tecnico-regulatorio-creditexplain-br.md) — detalhe técnico-regulatório, matrizes e controles de evidência.
4. [`corpus-77-fontes.md`](corpus-77-fontes.md) — corpus histórico, hierarquia das fontes e refresh temporal.
5. [`experimentos-e-cicatrizes.md`](experimentos-e-cicatrizes.md) — evolução dos prompts, resultados, erros encontrados e correções.

## Para quem está começando

Se uma sigla ou termo interromper a leitura, consulte primeiro o mapa de siglas e a **Parte XIV — Glossário comentado** do e-book. O mapa decodifica abreviações; o glossário desenvolve conceitos que exigem contexto.

## Integridade

O material é acadêmico e pedagógico. Não constitui parecer jurídico, política real de crédito, diagnóstico clínico ou sistema automatizado em produção. Fontes internacionais são tratadas como benchmarks quando não possuem força normativa no Brasil.
